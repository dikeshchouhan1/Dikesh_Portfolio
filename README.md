# Portfolio Website

This is my personal portfolio website built using **React.js** and **Tailwind CSS**.  
It shows my skills, projects, experience, and education in a clean and responsive layout.

## 🚀 Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- HTML
- CSS

- Responsive design
- Modern UI
- Skills section
- Projects section
- Experience section
- Education section
- Contact form (demo only)
